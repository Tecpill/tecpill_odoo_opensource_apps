Overview

HR Phone Extension Management is a comprehensive solution for managing internal phone extensions within your organization. Seamlessly integrated with Odoo's HR system, this module provides a centralized platform for tracking and managing employee phone extensions, making internal communication more efficient and organized.

Installation & Setup

  1. Download the module from Odoo Apps Store
  2. Install via Apps menu in your Odoo instance
  3. Configure by navigating to Employees → Phone Extensions
  4. Start creating extension records and assigning to employees

Requirements: Odoo 17.0, HR module (automatically installed)
