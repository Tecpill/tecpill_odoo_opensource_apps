Description

HR Phone Extension Management is a comprehensive solution designed to streamline internal communication within your organization. This module seamlessly integrates with Odoo's HR system to provide a centralized platform for tracking and managing employee phone extensions. With this module, businesses can:

  • Maintain a complete directory of phone extensions with employee assignments
  • Quickly search and locate employee extensions by name, department, or extension number
  • Track extension availability and status for better communication management
  • Organize extensions by department for improved internal structure
  • Provide public access to employee extensions for easy internal lookups
  • Log activities and communications related to extension assignments
  • Prepare infrastructure for future VOIP integration and call management features

Installation Notes

  • Install via the Apps menu in your Odoo instance

Usage Guide

How to Create and Assign Extensions

Navigate to Employees → Configuration → Phone Extensions and create new extension records. Each extension can be assigned to an employee and includes:

  • Extension number (unique identifier)
  • Employee assignment (optional, can be assigned later)
  • Department information (auto-filled from employee)
  • Extension status (active/inactive)
  • Additional notes and details
  • Activity tracking through chatter integration

Searching and Filtering Extensions

Use the powerful search and filter capabilities to quickly find extensions:

  • Search by extension number, employee name, or department
  • Filter by assigned/unassigned status
  • Group by department or extension range
  • Use quick filters for common queries

Managing Extension Assignments

Extensions can be easily assigned and reassigned to employees:

  • Assign directly from the extension record
  • Assign from the employee profile
  • View all extensions assigned to an employee
  • Track assignment history through activity logs
