How It Works

📞 Phone Normalization

The module automatically normalizes all phone numbers:

  • (828)-316-0593 → 8283160593
  • 055 123 4567 → 551234567 (with strip leading zero enabled)
  • 00966-55-123-4567 → 966551234567

Removes all spaces, dashes, parentheses, and handles international prefixes (00). Leading zero stripping is configurable for regional needs.

🎯 Smart Search Priority

  1. Exact Match: Finds exact normalized number
  2. Prefix Match: Finds numbers starting with search term
  3. Suffix Match: Finds numbers ending with search term
  4. Name Fallback: Standard name search if not a phone number

Installation & Configuration

📦 Installation

  1. Install from Odoo Apps Store or upload manually
  2. Click Install - all dependencies are automatic
  3. Module is ready to use immediately
  4. Existing phone numbers are automatically normalized

⚙️ Configuration

Navigate to: Settings → General Settings → Contact Search by Phone

  • Minimum Digits: Set how many digits trigger phone search (default: 3)
  • Enforce Unique Phones: Enable to prevent duplicate phone numbers
  • Show Phone in Search: Display phone number alongside contact name
  • Strip Leading Zero: Remove leading 0 from numbers (e.g., 0551234567 → 551234567)

🔧 Technical Requirements

  • ✓ Odoo 19.0
  • ✓ PostgreSQL 12+ (for text_pattern_ops indexes)
  • ✓ contacts module (base dependency)
  • ✓ No external libraries required

Usage Guide

How to Search by Phone

  1. Go to any contact selection field (Customer, Vendor, Partner, etc.)
  2. Type a phone number - full or partial
  3. Example searches:
    • 828 - finds all numbers starting with 828
    • 8283160593 - finds exact number
    • 828-316 - normalized automatically
    • (828)-316-0593 - any format works
  4. Contact appears instantly in dropdown
  5. Select the contact to proceed
